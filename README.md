## Featured Work

### [Glycinate](https://github.com/omjikush09/Glycinate)

TypeScript, React, Docker, infrastructure, lambdas

A deployment platform for React apps. The repo is structured as a monorepo with a web app, infrastructure code, lambda services, and shared packages.

- Built around the idea of making React app deployments simpler.
- Includes deployment-focused architecture and supporting infra.
- Good example of how I think about product, backend workflows, and developer tooling together.

### [mediasoup-streaming](https://github.com/omjikush09/mediasoup-streaming)

TypeScript, WebRTC, mediasoup

A real-time media streaming project using mediasoup concepts.

- Explores WebRTC-style audio/video streaming architecture.
- Useful for understanding transports, producers, consumers, and real-time backend coordination.
- Part of my work around low-latency communication systems.
